## PR Description

Add 4 Iranian dialect groups to doculects.csv (encyclopedia volume 6):

- **tati_dialects** (36.5, 50.5): Tati dialects spoken in the Alborz mountains of northwestern Iran, near existing Tati language entry (41.4, 46.6) and other Caspian languages
- **semnan_dialects** (35.5, 53.5): Semnan region dialects, aligned with existing `semnani` entry (35.58, 53.40) in the same province
- **central_iran_dialects** (32.5, 52.5): Central Iran dialects covering Isfahan/Yazd region, midpoint between existing northwestern and southwestern Iranian languages
- **central_persian_desert_dialects** (33.5, 54.5): Dasht-e Kavir (Great Salt Desert) dialects, positioned in the central desert basin between Semnan and Yazd

All entries assigned to `north_west_iran` family and `irn` (Iran) country code, consistent with other volume 6 doculects.
